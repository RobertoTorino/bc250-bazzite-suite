# What is the BC-250?

The BC-250 is a compact computer board built around an AMD processor with Radeon graphics. It can run Linux and
games like a desktop PC. This suite provides tools made specifically for its hardware and for Bazzite.

The board became known through cryptocurrency-mining systems, including data-center deployments. It is sometimes
called a Bitcoin-mining board, but it is not a dedicated Bitcoin-mining chip: it combines a general-purpose CPU
with a GPU. GPU-based mining was used for other cryptocurrencies, while Bitcoin mining is now dominated by
special-purpose hardware.

After entering the second-hand market, the BC-250 attracted attention from PC enthusiasts as an unusual,
low-cost platform for Linux gaming and hardware experimentation.
