# RPCS3 Manager

Plays PS3 games on the **AMD BC-250** on **Bazzite** with [RPCS3](https://rpcs3.net): installs the RPCS3 build it was
tried with, installs your PS3 firmware through RPCS3, finds your games and adds them to Steam for Game Mode.

How to install and use it: [RPCS3 Manager in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/rpcs3-manager/).
