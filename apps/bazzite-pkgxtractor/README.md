# Bazzite pkgxtractor

Extracts package (.pkg) files into the folder layout the **shadPS4** emulator uses, on **Bazzite**: pick a package,
see its icon and `param.sfo`, extract it into `<output>/<TITLE_ID>/`. The Python + Qt port of the C++ tool
[pkgxtractor](https://github.com/RobertoTorino/pkgxtractor).

How to install and use it: [Bazzite pkgxtractor in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/bazzite-pkgxtractor/).
