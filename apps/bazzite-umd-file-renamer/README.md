# Bazzite UMD File Renamer

Renames PSP ISO images after what their `PARAM.SFO` says, on **Bazzite**: open a folder of `.iso` files, see each
game's ID, title, version and icon, pick a naming template such as `ULJM05437 - Ever17.iso`, and rename them all.
The Python + Qt port of the C++/Qt tool [UMD File Renamer](https://github.com/RobertoTorino/umd-file-renamer).

How to install and use it: [Bazzite UMD File Renamer in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/bazzite-umd-file-renamer/).
