# PCSX2 Manager

Plays PS2 games on the **AMD BC-250** on **Bazzite** with [PCSX2](https://pcsx2.net): installs the PCSX2 release it
was tried with, checks your PS2 BIOS, finds your games and adds them to Steam for Game Mode. Its Memory cards
window manages the saves on PCSX2's memory cards: import, export, copy, delete, new cards, format and check.

How to install and use it: [PCSX2 Manager in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/pcsx2-manager/).
