# shadPS4 Manager

Plays PS4 games on the **AMD BC-250** on **Bazzite** with [shadPS4](https://github.com/shadps4-emu/shadPS4): installs
the shadPS4 release it was tried with, finds your games, adds them to Steam for Game Mode and signs you in to shadNet,
shadPS4's online service.

How to install and use it: [shadPS4 Manager in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/shadps4-manager/).
