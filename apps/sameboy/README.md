# SameBoy Manager

Plays Game Boy and Game Boy Color games on the **AMD BC-250** on **Bazzite** with
[SameBoy](https://sameboy.github.io), as a core of [RetroArch](https://www.retroarch.com): installs RetroArch (a
Flatpak) and the core, finds your games and adds them to Steam for Game Mode.

How to install and use it: [SameBoy Manager in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/sameboy/).
