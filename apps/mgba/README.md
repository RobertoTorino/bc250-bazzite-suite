# mGBA Manager

Plays Game Boy Advance games on the **AMD BC-250** on **Bazzite** with [mGBA](https://mgba.io): installs a tested
mGBA release, finds your games and adds them to Steam for Game Mode.

How to install and use it: [mGBA Manager in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/mgba/).
