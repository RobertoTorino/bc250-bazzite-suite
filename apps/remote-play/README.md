# BC250 Remote Play

Remote Play for the **AMD BC-250** on **Bazzite**: find the PS4 and PS5 consoles on your network, wake them from
rest mode, register the board with them, and start a Remote Play session.

How to install and use it: [BC250 Remote Play in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/remote-play/).
