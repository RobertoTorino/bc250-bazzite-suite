# SwanStation Manager

Plays PS1 games on the **AMD BC-250** on **Bazzite** with [SwanStation](https://github.com/libretro/swanstation), a
core of [RetroArch](https://www.retroarch.com): installs RetroArch (a Flatpak) and the core, checks your PS1 BIOS,
finds your games and adds them to Steam for Game Mode.

How to install and use it: [SwanStation Manager in the manual](https://robertotorino.github.io/bc250-bazzite-suite/apps/swanstation/).
