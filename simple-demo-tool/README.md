# Simple Demo Tool

A standalone Qt app for recording BC250 Bazzite Suite installation demos on Bazzite. It is not installed by the
suite portal and uses its own Python environment.

How to install and use it: [Simple Demo Tool in the manual](https://robertotorino.github.io/bc250-bazzite-suite/other-tools/simple-demo-tool/).
